# A2 Personal Website

## Purpose
This website is my personal site for Assignment 2 in Intro to Visual Analytics.  
It works like a simple resume website. It introduces who I am, what I study, and what I have worked on.  
It also includes a separate page that shows my SVG visualizations.

## Technologies Used
- HTML: page structure and content
- CSS: layout, spacing, colors, and dark theme styling
- JavaScript: basic interactivity (theme toggle, back-to-top button, reveal-on-scroll)
- SVG: visualizations drawn with JavaScript inside the browser

## How to Navigate
- Home page: `index.html`  
  This has my introduction, education, skills, experience, and contact info.

- Visualizations page: `visualizations.html`  
  This page has two SVG outputs:
  1. Tint tradeoff chart (privacy vs visibility)
  2. Generative SVG art

- Theme toggle:
  Click the Theme button in the header to switch between light and dark mode.  
  The theme is saved, so when you reload the site it keeps the same mode.
